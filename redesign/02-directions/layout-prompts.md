# Layout Prompts — After Moodboard

Use these only after selecting 6–10 moodboard references. Goal: generate visual mocks, not code.

## Common instruction block

```text
Mobile-first. Start with a 390x844 phone frame. Do not design desktop first.
Use attached moodboard images as visual atmosphere; do not copy them literally.
No code. No generated readable Spanish text; use neutral placeholder text blocks.
Avoid generic landing patterns: no SaaS hero, no three-card feature grid, no glassmorphism, no blobs, no stock wellness cliché.
Tone: warm, human, tactile, grounded, prudent.
Primary action: reserve the next group encounter. Secondary action: ask about individual session / WhatsApp.
First fold must make the reservation path visible without becoming cold or transactional.
```

---

## Direction A — Mesa de reserva / tactile object

The page behaves like a real table where the visitor arranges the decision: date, place, questions, reservation and testimony feel like objects, not SaaS cards.

```text
Design a radical mobile-first visual mock for Rocío Ceverio’s public booking site.
Direction name: “Mesa de reserva / tactile object”.

Make the page feel like a calm work table: warm paper surfaces, tactile pieces, a documentary table image, small wooden constellation figures, subtle olive and clay accents. The next group encounter must be visible in the first fold as a physical reservation object with date/time/place and one strong primary action. The page should feel human and grounded, not like a conventional landing page.

Required mobile sections:
1. compact header
2. first fold with tactile reservation object + atmospheric image
3. gentle first-time reassurance
4. testimonials as notes or paper fragments
5. individual session as secondary path

Create desktop only as an adaptation after mobile. Use placeholder text blocks only.
```

Attach: 3–5 table/still-life moodboard images, one current mobile snapshot as “what to move away from”.

Evaluate: does the date/CTA remain clear, or did it become a decorative collage?

## Direction B — Ronda prepared room

The page opens on the prepared space, not on marketing. It feels like walking into the room before the encounter.

```text
Design a radical mobile-first visual mock for Rocío Ceverio’s public site.
Direction name: “Ronda prepared room”.

The experience should feel like entering a calm prepared group room before people arrive: chairs in circle, soft light, simple materials, a side table with wooden figures. The booking module should appear as a calm invitation, not a sales card. The layout should use vertical rhythm and quiet spatial cues rather than many cards.

First fold mobile must include:
- visual sense of a prepared room
- next encounter date/time as a quiet but clear module
- primary action to reserve
- a small trust cue for first-time participants

Avoid generic hero + cards. Avoid mystical props. Use placeholder text only.
```

Attach: 3–5 room/ronda moodboard images.

Evaluate: does it feel local/human, or does it look like a retreat/wellness stock image?

## Direction C — Editorial mobile booking poster

A strong mobile poster-like composition: immediate clarity, but with visual identity and tactile depth.

```text
Design a radical mobile-first visual mock for Rocío Ceverio’s public booking site.
Direction name: “Editorial mobile booking poster”.

Create a phone-first landing that feels like an editorial event poster and a booking flow merged together. Strong date module, tactile image crop, clear primary CTA, and one testimonial/trust cue in the first scroll. Use warm paper, dark ink, olive/clay accents and large confident typography blocks, but no readable generated text.

This should not look like a SaaS landing or eventbrite clone. It should be distinctive, calm and human. Desktop can become a wide editorial spread, but mobile is the source of truth.
```

Attach: 2–3 booking clarity references + 2–3 tactile moodboard images.

Evaluate: is it too transactional? If yes, soften with image/material; if no action is clear, reject.

---

## Template check questions

Reject a mock if:

- You could swap Rocío for any coach/therapist/wellness brand without noticing.
- It uses generic “hero + three cards + testimonials grid” without a unique visual driver.
- It hides date/CTA below atmospheric content.
- It depends on generated text baked into images.
- It creates a beautiful image but no implementable layout system.
